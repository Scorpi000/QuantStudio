# 因子框架改造方案：计算维度分离

## 1. 问题分析

### 1.1 当前设计的核心问题

#### 问题一：截面ID归属混乱

当前截面ID出现在多个位置，职责不清：

| 位置 | 类型 | 说明 |
|------|------|------|
| `Factor.__QS_ArgClass__.SectionIDs` | 因子参数 | 因子定义时绑定 |
| `FactorContext.SectionIDs` | 全局上下文 | 运行时默认值 |
| `FactorInitData.SectionIDs` | 初始化数据 | init_compute 传递 |
| `FactorState["SectionIDs"]` | 运行时状态 | 缓存和计算用 |
| `FactorOperator.DescriptorSection` | 算子配置 | 描述子截面映射 |

**根本问题**：截面ID到底是"因子的属性"还是"调用的参数"？

#### 问题二：时点维度同样存在

时点标尺（DTRuler）也有同样的问题：
- 因子A在日度频率计算
- 因子B在月度频率计算
- 当前强制要求所有因子的 DTRuler 保持一致

#### 问题三：缓存键设计缺陷

当前缓存使用 `QSID` 作为键，但 `QSID` 不包含截面/时点信息：
- 不同截面的因子无法区分缓存
- 被迫在 `init_compute` 中做严格的截面一致性检查
- 同一因子无法被不同截面/时点复用

#### 问题四：初始化逻辑过度耦合

`init_compute` 方法（Factor.py 307-344行）职责过多：
- 时点范围处理
- 截面ID检查和绑定
- 缓存准备
- 依赖节点初始化数据传递

### 1.2 问题场景

```python
# 场景1：同一因子被不同截面调用
close = ft.getFactor("close")

# 全市场计算
result_all = close.readData(ids=all_market, dts=dts)

# 沪深300计算
result_hs300 = close.readData(ids=hs300, dts=dts)
# 当前会报错：因子指定了不同的截面！

# 场景2：截面排名的两种语义
rank = SectionRank()(close)

# 语义A：全市场排名，返回沪深300
# 需要知道全市场才能计算排名
result_a = rank.readData(ids=hs300, dts=dts)

# 语义B：沪深300内部排名
# 只在300个里计算排名
result_b = rank.readData(ids=hs300, dts=dts)
# 两种语义在当前设计中无法区分

# 场景3：不同频率的因子组合
daily_ma = TimeOperation(descriptors=[close], args={"Operator": makeMA(5)})
monthly_return = TimeOperation(descriptors=[close], args={"Operator": makeReturn()})

# 想要组合这两个因子，但它们的 DTRuler 不同
combined = daily_ma + monthly_return
# 当前会因为 DTRuler 不一致而报错
```

## 2. 设计理念

### 2.1 核心思想：计算维度 vs 返回维度

```
因子定义：我是什么（计算逻辑）
计算维度：我需要知道谁（完整计算范围）
返回维度：用户想要谁的结果（可能更小）
缓存：按（因子 + 计算维度）存储
```

### 2.2 两个维度的含义

| 维度 | 计算维度 | 返回维度 |
|------|----------|----------|
| **截面** | 因子计算需要的完整证券列表 | 用户请求返回的证券列表 |
| **时点** | 因子计算需要的完整时点序列 | 用户请求返回的时点序列 |
| **示例** | 截面排名需要知道全市场 | 用户只想要沪深300的结果 |
| **缓存** | 参与缓存键生成 | 不影响缓存 |

### 2.3 三个组件的职责划分

| 组件 | 职责 | 配置示例 |
|------|------|----------|
| **算子（FactorOperator）** | 定义"怎么算"、"需要什么截面/时点"（算子语义） | `DescriptorSection`, `DescriptorDTRuler` |
| **因子（Factor）** | 定义"返回什么"、管理缓存 | `SectionIDs`, `readData(ids)` |
| **缓存** | 按（因子QSID + 截面哈希 + 时点哈希）存储 | `make_cache_key` |

**示例：截面排名**
- 算子：`SectionRank(DescriptorSection=[all_market])` - 定义"在全市场排名"
- 因子：`rank.readData(ids=hs300, section_ids=all_market)` - 返回沪深300的结果

### 2.4 设计原则

1. **职责分离**：算子定义语义，因子管理维度，缓存自动隔离
2. **运行时灵活**：维度在调用时指定，而非初始化时绑定
3. **缓存隔离**：不同计算维度自动隔离
4. **向后兼容**：保持原有API接口可用

### 3.1 缓存键生成

# QuantStudio/Factor/FactorCache.py

import hashlib
from typing import Optional, List
import datetime as dt


def make_cache_key(
    qsid: str, 
    section_ids: Optional[List[str]] = None,
    dtruler: Optional[List[dt.datetime]] = None
) -> str:
    """生成缓存键 = 因子QSID + 维度哈希
    
    Args:
        qsid: 因子的QSID
        section_ids: 计算截面，None表示不参与哈希
        dtruler: 计算时点标尺，None表示不参与哈希
        
    Returns:
        缓存键字符串
    """
    parts = [qsid]
    if section_ids:
        # 截面排序后哈希，确保顺序无关
        parts.append(f"s:{','.join(sorted(section_ids))}")
    if dtruler:
        parts.append(f"d:{','.join(str(d) for d in dtruler)}")
    return hashlib.md5("|".join(parts).encode()).hexdigest()[:16]

```python
# QuantStudio/Factor/Factor.py

class Factor(Node):
    """因子对象
    
    因子是计算图中的节点，定义了计算逻辑。
    计算维度（截面、时点）在调用时指定，而非初始化时绑定。
    """
    
    class __QS_ArgClass__(Node.__QS_ArgClass__):
        Name: str = Field(default="Factor", frozen=True, title="名称")
        Meta: dict = Field(default={}, title="元信息", frozen=False, exclude=True)
        
        # 计算维度配置（可选）
        SectionIDs: Optional[List[str]] = Field(
            default=None, 
            frozen=True,
            title="截面ID",
            description="固定计算截面，None表示每次调用时决定"
        )
        DTRuler: Optional[List[dt.datetime]] = Field(
            default=None,
            frozen=True, 
            title="时点标尺",
            description="固定计算时点标尺，None表示每次调用时决定"
        )
        
        CacheEnabled: bool = Field(default=True, frozen=True, title="启用缓存", repr=False)
    
    def __init__(
        self, 
        ft: Optional["FactorTable"] = None, 
        descriptors: List["Factor"] = [], 
        extra_deps: List[Node] = [], 
        args: dict = {}, 
        config_file: Optional[str] = None, 
        **kwargs
    ):
        """初始化因子对象

        Args:
            ft: 因子所属的因子表对象
            descriptors: 因子依赖的因子(描述子)列表
            extra_deps: 因子依赖的其他计算节点列表
            args: 指定的对象参数集
            config_file: 配置文件路径
        """
        if ft and descriptors:
            raise __QS_Error__("因子表和描述子列表不能都存在!")
        
        self._FactorTable = ft
        self._Descriptors = descriptors
        self._ExtraDeps = extra_deps
        self._cache = None  # 运行时设置
        
        kwargs.pop("deps", [])
        if ft:
            return super().__init__(deps=[ft] + extra_deps, args=args, config_file=config_file, **kwargs)
        else:
            return super().__init__(deps=descriptors + extra_deps, args=args, config_file=config_file, **kwargs)
    
    def set_cache(self, cache: "FactorCache"):
        """设置缓存对象（运行时调用）"""
        self._cache = cache
    
    @property
    def FactorTable(self) -> Optional["FactorTable"]:
        """因子所属的因子表"""
        return self._FactorTable

    @property
    def Descriptors(self) -> List["Factor"]:
        """因子所依赖的因子列表"""
        if self._FactorTable:
            return []
        else:
            return self._Descriptors.copy()
    
    def _resolve_calc_params(
        self, 
        ids: List[str], 
        dts: List[dt.datetime],
        section_ids: Optional[List[str]] = None,
        dt_ruler: Optional[List[dt.datetime]] = None
    ) -> Tuple[List[str], List[dt.datetime]]:
        """解析计算参数
        
        优先级：调用者参数 > 因子配置 > 请求参数
        
        Args:
            ids: 请求返回的证券列表
            dts: 请求返回的时点列表
            section_ids: 调用者指定的计算截面（覆盖因子配置）
            dt_ruler: 调用者指定的计算时点标尺（覆盖因子配置）
            
        Returns:
            (计算截面, 计算时点标尺)
        """
        # 确定计算截面
        if section_ids is not None:
            actual_section = section_ids
        elif self._QSArgs.SectionIDs is not None:
            actual_section = self._QSArgs.SectionIDs
        else:
            actual_section = ids
            
        # 确定计算时点
        if dt_ruler is not None:
            actual_dtruler = dt_ruler
        elif self._QSArgs.DTRuler is not None:
            actual_dtruler = self._QSArgs.DTRuler
        else:
            actual_dtruler = dts
            
        return actual_section, actual_dtruler
    
    def readData(
        self, 
        ids: List[str], 
        dts: List[dt.datetime],
        section_ids: Optional[List[str]] = None,
        dt_ruler: Optional[List[dt.datetime]] = None
    ) -> pd.DataFrame:
        """读取因子数据
        
        Args:
            ids: 返回的证券列表
            dts: 返回的时点列表
            section_ids: 计算截面（覆盖因子配置），None表示使用ids
            dt_ruler: 计算时点标尺（覆盖因子配置），None表示使用dts
            
        Returns:
            DataFrame(index=dts, columns=ids)
        """
        # 解析计算参数
        actual_section, actual_dtruler = self._resolve_calc_params(
            ids, dts, section_ids, dt_ruler
        )
        
        # 生成缓存键
        cache_key = make_cache_key(self.QSID, actual_section, actual_dtruler)
        
        # 尝试读取缓存
        if self._QSArgs.CacheEnabled and self._cache:
            cached = self._cache.read(cache_key)
            if cached is not None:
                # 缓存命中，reindex返回用户请求的范围
                return cached.reindex(index=dts, columns=ids)
        
        # 缓存未命中，执行计算
        result = self._compute(actual_section, actual_dtruler)
        
        # 写入缓存
        if self._QSArgs.CacheEnabled and self._cache:
            self._cache.write(cache_key, result)
        
        # 返回用户请求的范围
        return result.reindex(index=dts, columns=ids)
    
    def _compute(self, ids: List[str], dts: List[dt.datetime]) -> pd.DataFrame:
        """实际计算逻辑，子类实现
        
        Args:
            ids: 计算截面
            dts: 计算时点
            
        Returns:
            DataFrame(index=dts, columns=ids)
        """
        if self._FactorTable:
            return self._FactorTable.readData(
                factor_names=[self._QSArgs.Name], 
                ids=ids, 
                dts=dts
            ).iloc[0]
        raise NotImplementedError
    
    def getID(self, idt: Optional[dt.datetime] = None, **kwargs) -> List[str]:
        """获取 ID 序列"""
        if self._QSArgs.SectionIDs is not None:
            return self._QSArgs.SectionIDs
        if self._FactorTable is not None:
            return self._FactorTable.getID(ifactor_name=self._QSArgs.Name, idt=idt, **kwargs)
        return []

    def getDateTime(
        self, 
        iid: Optional[str] = None, 
        start_dt: Optional[dt.datetime] = None, 
        end_dt: Optional[dt.datetime] = None, 
        **kwargs
    ) -> List[dt.datetime]:
        """获取时点序列"""
        if self._QSArgs.DTRuler is not None:
            return self._QSArgs.DTRuler
        if self._FactorTable is not None:
            return self._FactorTable.getDateTime(
                ifactor_name=self._QSArgs.Name, 
                iid=iid, 
                start_dt=start_dt, 
                end_dt=end_dt, 
                **kwargs
            )
        return []
    
    def getMetaData(self, key: Optional[str] = None) -> Union[Any, pd.Series]:
        """获取因子的元信息"""
        if key:
            if key in self._QSArgs.Meta: 
                return self._QSArgs.Meta[key]
            elif self._FactorTable: 
                return self._FactorTable.getFactorMetaData(
                    factor_names=[self._QSArgs.Name], key=key
                ).loc[self._QSArgs.Name]
            else: 
                return None
        else:
            Meta = pd.Series(self._QSArgs.Meta)
            if self._FactorTable:
                Meta = Meta.combine_first(
                    self._FactorTable.getFactorMetaData(
                        factor_names=[self._QSArgs.Name], key=None
                    ).loc[self._QSArgs.Name]
                )
            return Meta
    
    def __getitem__(self, key):
        """支持 f[dt, ids] 索引"""
        if isinstance(key, tuple): 
            key += (slice(None),) * (2 - len(key))
        else: 
            key = (key, slice(None))
        if len(key) > 2: 
            raise IndexError("Too many indexers")
        DTs, IDs = key
        if DTs == slice(None): 
            DTs = None
        elif isinstance(DTs, dt.datetime): 
            DTs = [DTs]
        if IDs == slice(None): 
            IDs = None
        elif isinstance(IDs, str): 
            IDs = [IDs]
        return self.readData(IDs, DTs)
    
    # 运算符重载（保持不变）
    def __add__(self, other):
        from QuantStudio.Factor.BasicOperator import add
        return add(self, other)
    
    # ... 其他运算符重载 ...
```

```python
class DataFactor(Factor):
    """数据因子：直接赋予数据产生的因子"""
    
    class __QS_ArgClass__(Factor.__QS_ArgClass__):
        Name: str = Field(default="DataFactor", frozen=True, title="名称")
        DataType: Literal["double", "string", "object"] = Field(
            default="double", frozen=True, title="数据类型"
        )
        LookBack: int = Field(default=0, title="回溯天数", frozen=True)

    def __init__(
        self, 
        data: Union[Any, pd.DataFrame, pd.Series], 
        args: dict = {}, 
        config_file: Optional[str] = None, 
        **kwargs
    ):
        """初始化数据因子对象

        Args:
            data: 构造因子的数据
            args: 指定的对象参数集
            config_file: 配置文件路径
        """
        super().__init__(ft=None, descriptors=[], args=args, config_file=config_file, **kwargs)
        self._Data = self._prepare_data(data)
    
    def _prepare_data(self, data):
        """准备内部数据"""
        if isinstance(data, pd.DataFrame):
            return data
        elif isinstance(data, pd.Series):
            if pd.api.types.is_datetime64_any_dtype(data.index):
                # 时序数据，扩展为DataFrame
                return pd.DataFrame(data)
            else:
                # 截面数据
                return data
        else:
            # 标量
            return data
    
    def _compute(self, ids: List[str], dts: List[dt.datetime]) -> pd.DataFrame:
        """直接从内部数据reindex"""
        if isinstance(self._Data, pd.DataFrame):
            return self._Data.reindex(index=dts, columns=ids)
        elif isinstance(self._Data, pd.Series):
            # 根据Series的index类型判断是时序还是截面
            if pd.api.types.is_datetime64_any_dtype(self._Data.index):
                # 时序数据，扩展到所有ids
                data = pd.DataFrame(self._Data).reindex(index=dts)
                return pd.DataFrame(
                    np.repeat(data.values.reshape(-1, 1), len(ids), axis=1),
                    index=dts,
                    columns=ids
                )
            else:
                # 截面数据，扩展到所有dts
                return pd.DataFrame(
                    np.repeat(self._Data.values.reshape(1, -1), len(dts), axis=0),
                    index=dts,
                    columns=self._Data.index
                ).reindex(columns=ids)
        else:
            # 标量
            return pd.DataFrame(
                self._Data,
                index=dts,
                columns=ids
            )
```

### 3.4 衍生因子重构

```python
class DerivativeFactor(Factor):
    """衍生因子
    
    衍生因子的计算维度由两部分决定：
    1. 算子的 DescriptorSection：算子语义需要的截面（如截面排名需要完整截面）
    2. 因子的 SectionIDs/DTRuler：用户请求的计算范围
    
    计算时取两者的交集/并集（取决于算子语义）。
    """
    
    class __QS_ArgClass__(Factor.__QS_ArgClass__):
        Name: str = Field(default="DerivativeFactor", frozen=True, title="名称", exclude=True)
        Operator: FactorOperator = Field(title="算子", frozen=True)
        ModelArgs: dict = Field(default={}, title="参数", frozen=True)
    
    def __init__(
        self, 
        descriptors: List[Factor], 
        extra_deps: List[Node] = [], 
        args: dict = {}, 
        config_file: Optional[str] = None, 
        **kwargs
    ):
        """初始化衍生因子"""
        Operator = args["Operator"]._QS_validate(*descriptors, **kwargs.pop("operator_kwargs", {}))
        args = {"Name": Operator._QSArgs.Name} | args | {"Operator": Operator}
        super().__init__(
            descriptors=descriptors, 
            extra_deps=extra_deps, 
            args=args, 
            config_file=config_file, 
            **kwargs
        )
        self._Operator = self._QSArgs.Operator
    
    def _get_descriptor_section(self, i: int, default: List[str]) -> List[str]:
        """获取描述子的计算截面
        
        优先从算子的 DescriptorSection 获取（算子语义需要的截面），
        如果算子未配置，则使用默认值（父因子的计算截面）。
        
        Args:
            i: 描述子索引
            default: 默认截面（父因子的计算截面）
            
        Returns:
            描述子的计算截面
        """
        # 算子的 DescriptorSection 是算子语义的一部分
        # 如截面排名需要知道完整截面
        if (hasattr(self._Operator._QSArgs, "DescriptorSection") and 
            i < len(self._Operator._QSArgs.DescriptorSection) and
            self._Operator._QSArgs.DescriptorSection[i] is not None):
            return self._Operator._QSArgs.DescriptorSection[i]
        return default
    
    def _compute(self, ids: List[str], dts: List[dt.datetime]) -> pd.DataFrame:
        """计算衍生因子
        
        Args:
            ids: 计算截面
            dts: 计算时点
            
        Returns:
            计算结果
        """
        # 确定每个描述子的计算截面
        # 截面来源：算子的 DescriptorSection（算子语义）或 ids（默认）
        descriptor_data = []
        for i, desc in enumerate(self._Descriptors):
            desc_section = self._get_descriptor_section(i, ids)
            
            # 调用描述子的readData
            # 描述子的计算截面由算子决定，返回截面也是 desc_section
            desc_data = desc.readData(
                ids=desc_section,
                dts=dts,
                section_ids=desc_section
            )
            descriptor_data.append(desc_data)
        
        # 应用算子
        if self._Operator._QSArgs.InputFormat == "numpy":
            arrays = [df.values for df in descriptor_data]
            result = self._Operator.calcData(
                context=None,
                factor=self,
                ids=ids,
                dts=dts,
                descriptor_data=arrays,
                dt_ruler=dts,
                section_ids=ids
            )
            return pd.DataFrame(result, index=dts, columns=ids)
        else:
            return self._Operator.calcData(
                context=None,
                factor=self,
                ids=ids,
                dts=dts,
                descriptor_data=descriptor_data,
                dt_ruler=dts,
                section_ids=ids
            )
    
    def getMetaData(self, key: Optional[str] = None) -> Union[Any, pd.Series]:
        """获取因子的元信息"""
        DataType = self._Operator._QSArgs.DataType
        if key is None:
            return pd.Series({"DataType": DataType, **self._QSArgs.Meta})
        elif key == "DataType":
            return DataType
        else:
            return self._QSArgs.Meta.get(key, None)
```

```python
class TimeOperation(DerivativeFactor):
    """时序算子：需要回溯历史数据
    
    时序算子的关键配置：
    - LookBack: 每个描述子的回溯期数
    - StartDT: 每个描述子的起始时点（扩张窗口模式）
    - DescriptorDTRuler: 每个描述子的时点标尺（决定回溯的频率）
    """
    
    class __QS_ArgClass__(DerivativeFactor.__QS_ArgClass__):
        Name: str = Field(default="TimeOperation", frozen=True, title="名称", exclude=True)
        Operator: TimeOperator = Field(title="算子", frozen=True)
        LookBack: List[int] = Field(default=[], title="回溯期数", frozen=True)
        StartDT: List[Optional[dt.datetime]] = Field(default=[], title="起始时点", frozen=True)
        iInitFactor: int = Field(default=-1, title="起始因子", frozen=True)
        DescriptorDTRuler: List[Optional[List[dt.datetime]]] = Field(
            default=[], 
            title="描述子时点标尺", 
            frozen=True,
            description="每个描述子的时点标尺，None表示使用因子的时点标尺。"
                       "决定回溯的频率：日度标尺回溯N天，月度标尺回溯N个月。"
        )
    
    def _get_descriptor_dtruler(self, i: int, default: List[dt.datetime]) -> List[dt.datetime]:
        """获取描述子的时点标尺
        
        Args:
            i: 描述子索引
            default: 默认时点标尺（因子的时点标尺）
            
        Returns:
            描述子的时点标尺
        """
        if (i < len(self._QSArgs.DescriptorDTRuler) and 
            self._QSArgs.DescriptorDTRuler[i] is not None):
            return self._QSArgs.DescriptorDTRuler[i]
        return default
    
    def _compute(self, ids: List[str], dts: List[dt.datetime]) -> pd.DataFrame:
        """时序算子需要额外的历史数据
        
        计算逻辑：
        1. 获取描述子的时点标尺（决定回溯频率）
        2. 根据 LookBack/StartDT 计算需要的历史时点
        3. 从描述子读取数据
        """
        descriptor_data = []
        
        for i, desc in enumerate(self._Descriptors):
            lookback = self._QSArgs.LookBack[i] if i < len(self._QSArgs.LookBack) else 0
            start_dt = self._QSArgs.StartDT[i] if i < len(self._QSArgs.StartDT) else None
            
            # 获取描述子的时点标尺（决定回溯频率）
            desc_dtruler = self._get_descriptor_dtruler(i, dts)
            
            # 计算需要的历史时点
            if start_dt is not None:
                # 扩张窗口模式：从 start_dt 开始
                extended_dts = [d for d in desc_dtruler if start_dt <= d <= dts[-1]]
            elif lookback > 0:
                # 滚动窗口模式：从当前时点回溯 lookback 期
                # 注意：这里的"期"由描述子的时点标尺决定
                current_idx = len([d for d in desc_dtruler if d <= dts[-1]])
                start_idx = max(0, current_idx - lookback)
                extended_dts = desc_dtruler[start_idx:current_idx]
            else:
                extended_dts = dts
            
            # 获取描述子的计算截面
            desc_section = self._get_descriptor_section(i, ids)
            
            # 读取描述子数据
            desc_data = desc.readData(
                ids=desc_section,
                dts=extended_dts,
                section_ids=desc_section,
                dt_ruler=desc_dtruler  # 使用描述子的时点标尺
            )
            descriptor_data.append(desc_data)
        
        # 应用时序算子
        return self._apply_time_operator(ids, dts, descriptor_data)
    
    def _apply_time_operator(
        self, 
        ids: List[str], 
        dts: List[dt.datetime], 
        descriptor_data: List[pd.DataFrame]
    ) -> pd.DataFrame:
        """应用时序算子"""
        # 具体实现取决于算子类型
        # 这里简化处理
        return self._Operator.calcData(
            context=None,
            factor=self,
            ids=ids,
            dts=dts,
            descriptor_data=descriptor_data,
            dt_ruler=dts,
            section_ids=ids
        )
```

```python
class FactorCache:
    """因子数据缓存
    
    缓存键由 make_cache_key 函数生成，格式为：
    {factor_qsid}_{section_hash}_{dtruler_hash}
    """
    
    def __init__(self, cache_dir: str):
        self._cache_dir = cache_dir
        self._cached_dt_range = {}  # {key: DataFrame(columns=["StartDT", "EndDT"])}
    
    def read(
        self, 
        key: str,
        dt_range: Optional[Tuple[dt.datetime, dt.datetime]] = None
    ) -> Optional[pd.DataFrame]:
        """读取缓存
        
        Args:
            key: 缓存键（由 make_cache_key 生成）
            dt_range: 请求的时点范围
            
        Returns:
            缓存的数据，None表示缓存未命中
        """
        # 检查时点范围是否覆盖
        cached_range = self._cached_dt_range.get(key)
        if cached_range is None:
            return None
        
        if dt_range and not self._range_covered(cached_range, dt_range):
            return None
        
        # 读取数据
        return self._read_from_disk(key)
    
    def write(
        self, 
        key: str, 
        data: pd.DataFrame
    ):
        """写入缓存
        
        Args:
            key: 缓存键（由 make_cache_key 生成）
            data: 要缓存的数据
        """
        # 写入数据
        self._write_to_disk(key, data)
        
        # 更新时点范围
        self._update_dt_range(key, (data.index[0], data.index[-1]))
        
        # 更新时点范围
        self._update_dt_range(key, (data.index[0], data.index[-1]))
    
    def _range_covered(
        self, 
        cached_range: pd.DataFrame, 
        dt_range: Tuple[dt.datetime, dt.datetime]
    ) -> bool:
        """检查缓存的时点范围是否覆盖请求的范围"""
        start, end = dt_range
        covered = cached_range[
            (cached_range["StartDT"] <= start) & 
            (cached_range["EndDT"] >= end)
        ]
        return not covered.empty
    
    def _update_dt_range(
        self, 
        key: str, 
        dt_range: Tuple[dt.datetime, dt.datetime]
    ):
        """更新缓存的时点范围"""
        if key not in self._cached_dt_range:
            self._cached_dt_range[key] = pd.DataFrame(
                [dt_range], columns=["StartDT", "EndDT"]
            )
        else:
            # 合并时点范围
            existing = self._cached_dt_range[key]
            new_row = pd.DataFrame([dt_range], columns=["StartDT", "EndDT"])
            self._cached_dt_range[key] = pd.concat(
                [existing, new_row]
            ).sort_values("StartDT").reset_index(drop=True)
    
    def _read_from_disk(self, key: str) -> Optional[pd.DataFrame]:
        """从磁盘读取缓存数据"""
        # 具体实现取决于缓存格式（HDF5、Feather等）
        raise NotImplementedError
    
    def _write_to_disk(self, key: str, data: pd.DataFrame):
        """将数据写入磁盘缓存"""
        # 具体实现取决于缓存格式（HDF5、Feather等）
        raise NotImplementedError


class FeatherFactorCache(FactorCache):
    """基于Feather格式的因子缓存"""
    
    def __init__(self, cache_dir: str, dtruler: List[dt.datetime]):
        super().__init__(cache_dir, dtruler)
        os.makedirs(cache_dir, exist_ok=True)
    
    def _read_from_disk(self, key: str) -> Optional[pd.DataFrame]:
        """从Feather文件读取"""
        path = os.path.join(self._cache_dir, f"{key}.feather")
        if not os.path.exists(path):
            return None
        return pd.read_feather(path).set_index("index")
    
    def _write_to_disk(self, key: str, data: pd.DataFrame):
        """写入Feather文件"""
        path = os.path.join(self._cache_dir, f"{key}.feather")
        data.reset_index().to_feather(path)
```

```python
class FactorTable(Node):

        self, 
        factor_names: List[str], 
        ids: List[str], 
        dts: List[dt.datetime],

        dt_ruler: Optional[List[dt.datetime]] = None,

    ) -> Panel:

            factor_names: 因子名称列表
            ids: 返回的ID序列
            dts: 返回的时点序列

        Returns:
            Panel(item=factor_names, major_axis=dts, minor_axis=ids)

                ids=ids,
                dts=dts,
                section_ids=actual_section,
                dt_ruler=actual_dts
            )
            results.append(result)
        
        return Panel({name: result for name, result in zip(factor_names, results)})
```

## 8. 总结

本方案的核心改进：

1. **职责分离**：截面/时点从"因子属性"变为"调用参数"
2. **缓存隔离**：不同计算维度自动隔离，无需手动管理
3. **灵活性提升**：运行时可动态指定计算维度
4. **代码简化**：移除复杂的初始化检查逻辑
5. **统一模型**：截面和时点用同一套机制处理

这个设计更符合"计算图"的本质——因子是计算节点，维度是输入参数，缓存按输入存储。
